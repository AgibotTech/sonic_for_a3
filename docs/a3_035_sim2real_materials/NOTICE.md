# Asset and Source Notices

The A3 URDF, MJCF, and meshes are derived from the public
[A3/A3U robot model](https://github.com/AgibotTech/A3-A3U-robot-model). The
accompanying Mulan PSL v2 license is in [`licenses/`](licenses/).

The five raw passive-foot CSVs are limited to the files listed in
`03_passive_foot/raw/raw_manifest.csv`; the source archive, photographs, and
Word reports are not included.

The solver directory contains public headers and a built static library. It
does not contain the solver implementation source. Code snapshots are reading
copies; use the repository paths referenced by each snapshot README for runtime
changes.
